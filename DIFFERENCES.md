# Отличия от основного шаблона репозитория

## Основные отличия

### 1. Независимость
- **Оригинальный шаблон**: Автореферат (папка `Synopsis/`) использует общие файлы из папки `common/` и связан с основной диссертацией
- **Этот шаблон**: Полностью независимый, все файлы находятся в одной папке `AutoreferatTemplate/`

### 2. Структура файлов
- **Оригинальный шаблон**:
  - Общие данные в `common/data.tex`
  - Общие пакеты в `common/packages.tex`
  - Общие стили в `common/styles.tex`
  - Специфичные настройки в `Synopsis/`

- **Этот шаблон**:
  - Все в одной папке
  - `data.tex` - все данные диссертации
  - `packages.tex` - все пакеты
  - `styles.tex` - все стили
  - Нет зависимостей от внешних папок

### 3. Работа с изображениями
- **Оригинальный шаблон**:
  ```latex
  \graphicspath{{images/}{Synopsis/images/}}
  ```
  Изображения могут браться из общей папки и из `Synopsis/images/`

- **Этот шаблон**:
  ```latex
  \graphicspath{{images/}}
  ```
  Изображения только из локальной папки `images/`

### 4. Библиография
- **Оригинальный шаблон**: Поддержка BibTeX и BibLaTeX через файлы `biblio/author.bib` и `biblio/external.bib`
- **Этот шаблон**: Упрощенный вариант без автоматической библиографии, список публикаций вводится вручную в `content.tex`

### 5. Сложность настройки
- **Оригинальный шаблон**: Множество опций в `common/setup.tex`, выбор движков, шрифтов, режимов
- **Этот шаблон**: Минимальные настройки, все основное уже сконфигурировано

### 6. Общая характеристика работы
- **Оригинальный шаблон**: Использует `common/characteristic.tex` с макросами
- **Этот шаблон**: Все тексты определены в `data.tex` как переменные

## Преимущества этого шаблона

1. ✅ **Простота**: Все файлы в одной папке
2. ✅ **Независимость**: Не нужна основная диссертация
3. ✅ **Портативность**: Можно скопировать папку и работать отдельно
4. ✅ **Понятность**: Меньше файлов, проще структура
5. ✅ **Локальные изображения**: Картинки хранятся рядом с текстом

## Когда использовать какой шаблон

### Используйте основной шаблон (`Synopsis/`), если:
- Пишете диссертацию и автореферат одновременно
- Хотите синхронизировать данные между диссертацией и авторефератом
- Нужна продвинутая работа с библиографией
- Требуются все возможности настройки

### Используйте этот шаблон (`AutoreferatTemplate/`), если:
- Нужен только автореферат
- Диссертация уже готова или пишется отдельно
- Хотите простой и понятный шаблон
- Предпочитаете работать с одной папкой
- Автореферат пишется отдельным человеком/в другое время

## Миграция

### Из основного шаблона в этот
1. Скопируйте данные из `common/data.tex` в `data.tex`
2. Скопируйте содержание из `Synopsis/content.tex` в `content.tex`
3. Скопируйте изображения из `Synopsis/images/` в `images/`

### Из этого шаблона в основной
1. Скопируйте данные из `data.tex` в `common/data.tex`
2. Скопируйте содержание из `content.tex` в `Synopsis/content.tex`
3. Скопируйте изображения из `images/` в `Synopsis/images/`
