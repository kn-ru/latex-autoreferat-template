# Шаблон автореферата диссертации

Это самостоятельный шаблон для автореферата кандидатской диссертации.

## Структура файлов

- **autoreferat.tex** - главный файл (компилировать этот файл)
- **data.tex** - основные сведения о диссертации (ФИО, название, специальность и т.д.)
- **content.tex** - содержание автореферата
- **title.tex** - титульный лист
- **packages.tex** - подключаемые пакеты LaTeX
- **styles.tex** - стили оформления
- **setup.tex** - настройки шаблона
- **images/** - папка для изображений

## Как использовать

1. Заполните файл **data.tex** своими данными (ФИО, название работы, специальность и т.д.)
2. Напишите содержание автореферата в файле **content.tex**
3. При необходимости добавьте изображения в папку **images/**
4. Скомпилируйте файл **autoreferat.tex**:
   ```bash
   pdflatex autoreferat.tex
   biber autoreferat  # если используете библиографию
   pdflatex autoreferat.tex
   pdflatex autoreferat.tex
   ```

## Вставка изображений

Изображения вставляются из папки **images/** рядом с tex-файлом:

```latex
\begin{figure}[ht]
    \centering
    \includegraphics[width=0.8\linewidth]{images/название_файла}
    \caption{Подпись к рисунку}
    \label{fig:метка}
\end{figure}
```

## Формат

- Формат: A5 (стандарт для автореферата)
- Шрифт: 10pt
- Интервал: одинарный
- Поля настроены согласно ГОСТ Р 7.0.11-2011
