# Автореферат диссертации

Автореферат кандидатской диссертации Русакова Константина Дмитриевича по специальности 2.3.8 «Информатика и информационные процессы».

## Информация о диссертации

**Автор:** Русаков Константин Дмитриевич
**Название:** Комплексная методика реидентификации людей в информационно-поисковых системах
**Специальность:** 2.3.8 — Информатика и информационные процессы
**Степень:** кандидат технических наук
**Организация:** ИПУ РАН (Институт проблем управления им. В.А. Трапезникова РАН)
**Научный руководитель:** Гончаренко Владимир Иванович, доктор технических наук, доцент
**Год:** 2026

## Структура файлов

- **autoreferat.tex** - главный файл (компилировать этот файл)
- **data.tex** - основные сведения о диссертации (ФИО, название, специальность и т.д.)
- **content.tex** - содержание автореферата
- **title.tex** - титульный лист
- **packages.tex** - подключаемые пакеты LaTeX
- **styles.tex** - стили оформления
- **setup.tex** - настройки шаблона
- **images/** - папка для изображений

## Быстрый старт

### Компиляция

```bash
# Простая компиляция (2 прохода)
pdflatex autoreferat.tex
pdflatex autoreferat.tex

# Или с помощью Makefile
make
```

### Результат

После компиляции создается файл **autoreferat.pdf** формата A5 (стандарт для автореферата).

## Основные разделы

Автореферат содержит:

1. **Титульный лист** - информация об авторе, названии работы, специальности
2. **Общая характеристика работы:**
   - Актуальность темы исследования
   - Степень разработанности темы
   - Цель работы
   - Задачи исследования (5 задач)
   - Методология и методы исследования
   - Объект и предмет исследования
   - Научная новизна (3 пункта)
   - Теоретическая и практическая значимость
   - Положения, выносимые на защиту (3 пункта)
   - Соответствие паспорту специальности 2.3.8
   - Достоверность результатов
   - Апробация работы
   - Личный вклад автора
   - Публикации (13 работ)
3. **Содержание работы** - описание глав диссертации
4. **Заключение** - основные результаты
5. **Список публикаций**

## Ключевые результаты

### Научная новизна

1. **Модифицированная функция потерь детектора YOLOv8** для детекции связанных объектов «силуэт человека–лицо» с коэффициентом λ
2. **Метод формирования дискриминативных эмбеддингов** на основе ViT и ArcFace для лица и силуэта
3. **Метод интеграции эмбеддингов** на основе байесовской модели и MAP-критерия

### Экспериментальные результаты

- **CUHK03:** Precision 95,65%, Recall 95,54%, F1 94,31%, mAP 95,65%
- **Market-1501:** mAP 98,3%
- **MARS:** mAP 89,2%

## Компиляция в различных средах

### TeXstudio
1. Откройте `autoreferat.tex`
2. Нажмите F5 или "Build & View"

### VSCode с LaTeX Workshop
1. Откройте `autoreferat.tex`
2. Нажмите Ctrl+Alt+B (Cmd+Alt+B на Mac)

### Overleaf
1. Загрузите все файлы
2. Установите главный файл: `autoreferat.tex`
3. Нажмите "Recompile"
