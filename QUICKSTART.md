# Быстрый старт

## За 5 минут до первого PDF

### 1. Заполните свои данные

Откройте файл [data.tex](data.tex) и замените примеры на свои данные:
- ФИО автора
- Название диссертации
- Специальность
- Научный руководитель
- Оппоненты
- Информация о защите

### 2. Напишите содержание

Откройте файл [content.tex](content.tex) и:
- Заполните общую характеристику работы (актуальность, цели, задачи и т.д.) используя переменные из `data.tex`
- Напишите содержание по главам
- Добавьте список публикаций

### 3. Добавьте изображения (если нужно)

Поместите файлы изображений (PDF, PNG, JPG) в папку [images/](images/).

### 4. Скомпилируйте

**Linux/Mac:**
```bash
make
```

**Windows (или вручную):**
```bash
pdflatex autoreferat.tex
pdflatex autoreferat.tex
```

### 5. Получите результат!

Готово! Файл `autoreferat.pdf` создан.

## Пример вставки изображения

В файле `content.tex`:

```latex
\begin{figure}[ht]
    \centering
    \includegraphics[width=0.8\linewidth]{мое_изображение}
    \caption{Подпись к рисунку}
    \label{fig:primer}
\end{figure}
```

## Часто задаваемые вопросы

**В: Как изменить размер шрифта?**
О: В файле [autoreferat.tex:6](autoreferat.tex#L6) измените `10pt` на нужный размер (например, `11pt` или `12pt`).

**В: Как изменить поля страницы?**
О: В файле [styles.tex](styles.tex) найдите секцию `\geometry{...}` и измените параметры `top`, `bottom`, `inner`, `outer`.

**В: Изображения не находятся**
О: Убедитесь, что файлы находятся в папке `images/` и что вы не указываете расширение в команде `\includegraphics`.

**В: Нужно ли указывать расширение файла изображения?**
О: Нет! Пишите просто `\includegraphics{image}`, а не `\includegraphics{image.pdf}`.

**В: Как добавить библиографию?**
О: В текущей версии шаблона список публикаций добавляется вручную в конце файла [content.tex](content.tex). Для автоматической библиографии используйте основной шаблон в папке `Synopsis/`.
