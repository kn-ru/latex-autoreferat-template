## 📊 Статистика

- **Всего файлов:** 13 tex/md файлов
- **Всего строк кода:** ~658 строк в tex файлах
- **Размер PDF:** ~119 КБ (7 страниц)
- **Формат:** A5, 10pt, ГОСТ Р 7.0.11-2011

## 🎯 Типичный рабочий процесс

```
1. Откройте data.tex → заполните данные
   ↓
2. Откройте content.tex → напишите текст
   ↓
3. Добавьте изображения в images/
   ↓
4. Запустите: make (или pdflatex autoreferat.tex)
   ↓
5. Получите autoreferat.pdf
```
