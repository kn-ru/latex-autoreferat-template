# Инструкция по компиляции автореферата

## Быстрый старт

### Вариант 1: Использование Makefile (Linux/Mac)

```bash
make
```

Эта команда скомпилирует автореферат и создаст файл `autoreferat.pdf`.

### Вариант 2: Ручная компиляция

```bash
pdflatex autoreferat.tex
pdflatex autoreferat.tex
```

Два прохода нужны для правильного формирования ссылок и номеров страниц.

## Команды Makefile

- `make` или `make all` - стандартная сборка (2 прохода)
- `make quick` - быстрая сборка (1 проход)
- `make clean` - удалить временные файлы
- `make distclean` - удалить все сгенерированные файлы, включая PDF
- `make view` - собрать и открыть PDF
- `make help` - показать справку

## Использование разных компиляторов

### PDFLaTeX (по умолчанию)

```bash
pdflatex autoreferat.tex
```

### XeLaTeX (для использования системных шрифтов)

```bash
xelatex autoreferat.tex
```

### LuaLaTeX

```bash
lualatex autoreferat.tex
```

## Компиляция в IDE

### TeXstudio

1. Откройте файл `autoreferat.tex`
2. Нажмите F5 или кнопку "Build & View"
3. PDF откроется автоматически

### Overleaf

1. Загрузите все файлы и папку `images/` в проект
2. Установите главный файл: `autoreferat.tex`
3. Нажмите "Recompile"

### VSCode с LaTeX Workshop

1. Откройте файл `autoreferat.tex`
2. Нажмите Ctrl+Alt+B (или Cmd+Alt+B на Mac)
3. PDF откроется в отдельной панели

## Требования

Должны быть установлены следующие пакеты LaTeX:

- memoir (класс документа)
- geometry (настройка полей)
- graphicx (работа с изображениями)
- hyperref (гиперссылки)
- amsmath, amsthm, amssymb (математика)
- babel или polyglossia (поддержка русского языка)

Обычно все эти пакеты входят в стандартные дистрибутивы:
- **TeX Live** (Linux, Mac, Windows)
- **MiKTeX** (Windows)
- **MacTeX** (Mac)

## Решение проблем

### Ошибка "Font not found"

Установите пакет PSCyr или используйте XeLaTeX с системными шрифтами.

### Кириллица отображается неправильно

Убедитесь, что все файлы сохранены в кодировке UTF-8.

### Изображения не находятся

Проверьте, что файлы изображений находятся в папке `images/`.

### Ссылки не работают

Запустите компиляцию дважды - сначала создаются метки, затем ссылки.
