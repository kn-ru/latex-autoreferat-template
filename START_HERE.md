# 🎓 НАЧНИТЕ ОТСЮДА

## Что это?

Это **самостоятельный шаблон автореферата** кандидатской диссертации по ГОСТ Р 7.0.11-2011.

## ⚡ За 3 шага до готового PDF

### Шаг 1: Заполните данные
Откройте файл [**data.tex**](data.tex) и замените примеры на свои данные:
```tex
\newcommand{\thesisAuthorLastName}{Ваша Фамилия}
\newcommand{\thesisTitle}{Название вашей диссертации}
...
```

### Шаг 2: Напишите содержание
Откройте файл [**content.tex**](content.tex) и напишите текст автореферата.
Там уже есть примеры для рисунков, формул и таблиц.

### Шаг 3: Скомпилируйте
```bash
make
```
или
```bash
pdflatex autoreferat.tex
pdflatex autoreferat.tex
```

**Готово!** Файл `autoreferat.pdf` создан! 🎉

## ❓ Частые вопросы

**Q: Как вставить картинку?**
```latex
\begin{figure}[ht]
    \centering
    \includegraphics[width=0.8\linewidth]{имя_файла}
    \caption{Подпись}
\end{figure}
```
Поместите файл в папку `images/`, расширение не указывайте.

**Q: Где заполнять актуальность, цели, задачи?**
В файле `data.tex` найдите переменные типа `\newcommand{\actualityText}{...}`

**Q: Нужно ли компилировать дважды?**
Да, для правильных ссылок и номеров страниц.

**Q: Какой формат получится?**
A5 (стандарт для автореферата), 10pt, одинарный интервал.
