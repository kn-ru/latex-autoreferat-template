# Папка для изображений

В эту папку помещайте все изображения для автореферата.

## Поддерживаемые форматы

- **PDF** (рекомендуется для векторной графики)
- **PNG** (для растровых изображений)
- **JPG/JPEG** (для фотографий)
- **EPS** (для векторной графики, если используется pdflatex)

## Как вставить изображение

В файле `content.tex`:

```latex
\begin{figure}[ht]
    \centering
    \includegraphics[width=0.8\linewidth]{название_файла}
    \caption{Подпись к рисунку}
    \label{fig:метка}
\end{figure}
```

**Важно:**
- Расширение файла указывать не нужно (.pdf, .png и т.д.)
- LaTeX автоматически выберет нужный формат
- Путь к файлу относительно папки `images/`

## Примеры

Для файла `images/график.pdf`:
```latex
\includegraphics[width=0.8\linewidth]{график}
```

Для файла `images/схема.png`:
```latex
\includegraphics[width=10cm]{схема}
```

## Размеры

Можно задавать разными способами:
- `width=0.8\linewidth` - 80% ширины текста
- `width=10cm` - абсолютная ширина
- `height=5cm` - высота
- `scale=0.5` - масштаб 50%
