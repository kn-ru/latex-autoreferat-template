# История изменений AutoreferatTemplate

## Версия 1.0 (2026-02-17)

### Первый релиз
- ✅ Создан самостоятельный шаблон автореферата
- ✅ Полная независимость от основной диссертации
- ✅ Все файлы в одной папке
- ✅ Локальная папка для изображений
- ✅ Соответствие ГОСТ Р 7.0.11-2011
- ✅ Формат A5, 10pt
- ✅ Поддержка pdfLaTeX, XeLaTeX, LuaLaTeX
- ✅ Makefile для удобной сборки
- ✅ Подробная документация

### Файлы
- `autoreferat.tex` - главный файл
- `data.tex` - данные диссертации
- `content.tex` - содержание
- `title.tex` - титульный лист
- `packages.tex` - пакеты
- `styles.tex` - стили
- `setup.tex` - настройки
- `README.md` - основная документация
- `QUICKSTART.md` - быстрый старт
- `COMPILE.md` - инструкция по компиляции
- `DIFFERENCES.md` - отличия от основного шаблона
- `Makefile` - система сборки
- `.gitignore` - исключения для git

### Особенности
- Простая структура файлов
- Понятные комментарии на русском языке
- Примеры вставки рисунков, формул и таблиц
- Готов к использованию "из коробки"
